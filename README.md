# 智校 · 移动端出勤率报表（规范重设计）

按《名师预约移动端交互设计规范》重做的出勤率报表移动端原型，单文件、无外部依赖，双击 `index.html` 即可打开。

## 覆盖的页面

| 页面 | 说明 |
| --- | --- |
| 身份选择 | 老师 / 班主任 / 学管师 / 校长，各自带数据范围说明 |
| 首页 | 常用功能、报表中心、云学辅、今日课表 |
| 出勤率报表 | 统计时段、筛选条件、整体概览、汇总维度、分组对比表、合计行、加载更多 |
| 课次明细 | 按课次展开计费/未计费拆分 |

## 覆盖的交互

- 身份切换、返回、底部 Tab
- 统计时段弹层：本月 / 上月 / 最近30天 / 自定义起止 + 非法区间校验
- 筛选条件弹层：学员范围（试听/临加/临调/补课）、授课身份（主教/助教，至少保留一项）
- 分组取值弹层：全部 / 多选 / 搜索 / 重置 / 非空校验
- 条件摘要 chips、恢复默认、汇总维度切换、分组行展开收起
- 课次明细入口、加载更多、返回恢复滚动位置
- 弹层关闭：关闭按钮 / 点遮罩 / ESC

## 与旧版的差异

- 视觉回到规范 token：`--xx-*` 色彩、17/16/14/12/11 字号阶梯、12px 页边距、卡片 10px / 控件 8px 圆角
- 分组表默认按出勤率升序，并补了合计行
- 多值维度（班级标签）标注"同一课次可计入多个标签"，合计行显示去重总数
- 人数为 0 的分组显示"未计入"，不再出现裸的 `—`
- 概览补充"缺勤人次"绝对值
- 所有箭头统一为固定尺寸矢量图标，位置对齐
- 弹层限制在手机框内，不再冲出屏幕
- 示例数据重新生成，各班出勤率拉开差异（旧版每行都是 9次/99人次/79.80%）

## 待产品确认

1. **校长身份 = 全校出勤数据**：旧版校长的数据范围是空实现、入口直接隐藏，这里按"校长看全校"补全。
2. **顶部淡蓝渐变**：规范写明"不使用渐变"，此处为还原观感保留，如要严格守规范可换为纯色浅底。
